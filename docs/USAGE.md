# 游栖使用指南

## 初次运行

安装版运行 `GameNest-v0.1.0-windows-amd64-setup.exe`，按中文向导安装后从桌面或开始菜单打开“游栖”。默认安装位置为 `%LOCALAPPDATA%\Programs\GameNest`，数据在其下的 `data/`。安装前请退出正在运行的游栖；如缺少 WebView2，安装时需要联网。

便携版运行 `游栖/游栖.exe`。新游戏库为空；右下角进入设置，添加扫描目录（每行一个完整路径，支持文件夹选择器），设置排除位置，然后点击扫描游戏。默认扫描 D 盘，可改为其他盘符或文件夹。

应用识别 Steam 安装记录和常见引擎目录，也支持 Epic、本地游戏。工具和运行库尽量排除，但结果仍可能需要人工核对。离线盘符不会覆盖旧清单；无法读取的子目录会被跳过并尽量保留已有记录。

范围之外或排除位置中的游戏移出清单，不删除游戏本体、编辑资料、图片或收藏。

## 浏览与启动

- 顶部切换全部游戏、最近游玩或收藏，来源下拉框筛选 Steam / Epic / 本地游戏。
- `Ctrl+F` 定位搜索，封面墙与列表视图可切换。
- 单击选中，双击或点击“开始游戏”启动，工作目录设为游戏目录。
- 右键卡片、点击“更多”或按 `Shift+F10` 打开操作菜单；方向键选择，`Escape` 关闭。
- “打开文件夹”在资源管理器定位程序；Windows 可能限制窗口抢焦点。
- 顶部主题按钮切换亮色、暗色与跟随系统，偏好自动保存。

## 名称、封面和背景

“编辑资料”可修改显示名称、选择扫描识别到的启动程序、上传 PNG / JPG / WebP 图片。Steam 支持数字 AppID、`appid=数字` 或完整商店链接；DLsite 支持 RJ 编号或作品名称；VNDB 支持作品检索。

“补全游戏资料”按现有匹配规则补全缺少的名称、封面及宽幅背景，保留手动名称和已有图片。Steam 查询先尝试港区（HK），再尝试国区（CN）；网络、地区和平台限制可能导致无结果。

遇到冲突或接近的候选时，点击“待确认”或“核对候选”，对照编号、平台及图片，选择“确认并应用”或“保留原资料”。匹配率仅为辅助线索，跨平台同名也需要核对。

SteamGridDB 为可选来源，需自行申请 API Key，在设置中保存并测试连接。社区图片需要手动选择，社区认证不代表一定为官方原画。已保存密钥不会返回界面，换 Windows 账号或电脑后需重新填写。

## 备份与迁移

退出应用后备份整个 `data/`，恢复时放回 `游栖.exe` 旁边。不要只复制某一份 JSON，否则图片或偏好可能缺失。更换游戏安装位置后需要重新扫描和核对启动程序。

旧版“游戏收藏馆”用户可将原程序旁完整的 `data/` 放到 `游栖.exe` 旁边继续使用。原本地 Python 原型不在当前开源发布范围内。

安装版覆盖升级不会覆盖已有游戏清单或其他个人配置。通过 Windows“已安装的应用”卸载时，程序、文档、快捷方式会被移除，个人 `data/` 和未知文件会保留；再次安装可继续使用保留的数据。便携版迁移到安装版时，请退出应用后将完整 `data/` 放到安装目录内，并先备份目标位置已有的资料。

## 浏览器预览及限制

```powershell
cd 游栖
./游栖.exe --preview
```

访问 `http://127.0.0.1:8787`。预览使用相同的 Go 后端、编译后的 Vue 界面及游戏库，并非只读演示；浏览器不支持原生文件选择及桌面窗口控制。正常启动不开放此端口。

目前只验证 Windows。在线服务可用性、第三方 API 变更及单款游戏登录器、运行库问题仍需按实际情况处理。仓库不分发游戏本体、个人收藏数据或 API Key。
